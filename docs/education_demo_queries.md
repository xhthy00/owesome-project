# 教育问数高质量提问 Demo（扬州市教育局专家视角 · 已对齐演示数据）

> 本文档面向**市/区县教育局基教处、教研室、督导室及学校管理层**，提供可直接在 Awesome-Data 教育模块使用的自然语言提问示例。
> **所有示例均已对照 `edu` 库真实演示数据校准**：学校（脱敏码）、考试名、班级、学号均取自库内实际存在的数据，可直接复制提问复现。
> 系统支持 9 类学情报告：`CLASS_OVERVIEW`、`GRADE_COMPARISON`、`SUBJECT_DIAGNOSIS`、`STUDENT_PROFILE`、`TREND_TRACKING`、`TIER_ALERT`、`GROUP_FEATURE`、`COMPREHENSIVE`、`DIAGNOSTIC_REPORT`。

## 六、提问公式（业务人员可复用）

```text
【范围】全市 / 某区县 / 某学校（脱敏码）/ 某班级 / 某学生
【对象】某年级（高三 / 高二）+ 某学科（或全科）
【时间】某次考试（高三3月 / 高三5月模拟 / 高二期末）/ 近N次考试 / 历次考试
【意图】总览 / 对比 / 诊断 / 趋势 / 预警 / 综合分析 / 结构化诊断
【输出要求】排名 / 薄弱点 / 分层名单 / 教学建议 / 区域均衡
```

**示例组合（可直接替换括号内参数）：**

> 全市【范围】高二年级【对象】数学期末统测【时间】的学科均衡性诊断【意图】，输出区县对比和薄弱学科名单【输出要求】。

## 八、使用说明

1. **数据范围**：当前演示库为扬州市高中数据（仅高三、高二年级），提问中的学校/区县/考试名请参照「〇、演示数据说明」。库中 `tb_score` / `tb_school` / `tb_exam` 等为标准分表，`tb_score_overview` 为宽表（考试批次），两套数据均可查。
2. **学校标识**：提问中的学校一律使用**脱敏码**（`sc.school_id` / `tb_school.name`，形如 `GZ_19D9D68D`），系统按 `sc.school_id` 精确过滤；**禁止引用 `tb_school.s_name` 明文校名**，`school_cipher.py` 会强制改写含 `s_name` 的 SQL 并剥离明文列。
3. **知识点诊断前提**：`SUBJECT_DIAGNOSIS` 的「逐题/知识点」分析依赖 `tb_exam_question_knowledge` 回填。当前可用的关联考试为**高二数学/生物/历史/政治/地理期末**；高三两场及高二化学/物理/语文/英语期末未关联，这类考试做知识点诊断会大量显示「未关联知识点」（小题得分率仍可用）。
4. **学生个体**：学生标识使用脱敏后的学号（如 `GZ_19D9D68D_85DE9080`），学号前缀即所在学校脱敏码，提问时可用「学生 + 学号」或直接粘贴学号。
5. 部分报告（如 `DIAGNOSTIC_REPORT`、`COMPREHENSIVE`）需要多次 SQL 查询和图表渲染，响应时间可能略长，建议在非高峰时段使用。
6. 若需要覆盖系统默认的及格线（60%）或优秀线（85%），可通过 `GET/PUT /api/v1/education/report-config` 调整。
