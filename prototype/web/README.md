# Awesome Data 全站交互原型

这个原型使用 Ant Design Pro 6 的 Umi Max 和布局插件，配合 React 19、Ant Design 6、Ant Design X 2 和 Ant Design Charts 2。需要 Node.js 22 或更新版本，可独立于业务服务运行。

```powershell
cd prototype/web
npm ci
npm run dev
```

打开 `http://127.0.0.1:4177/`。使用 `npm run build` 生成静态构建，或运行 `npm run preview` 预览该构建。

## 可体验的流程

- 学情总览：切换考试和学校，查看学科达线对比或进入异常详情。
- AI 问数：在全站侧栏新建或打开任务。点击推荐问题可填入输入框，发送后可查看任务进度、澄清选项和图表／数据／SQL 预览。
- 学情分析：选择学校与年级生成报告，在抽屉中预览并导出文本，也可从报告历史打开。
- 数据管理：浏览六类资源，搜索与筛选，查看详情，新增演示记录并模拟连接校验。
- 权限管理：编辑角色的功能权限和数据范围，跨页勾选成员后批量分配角色。
- 系统日志：在操作、访问和登录日志间切换，按关键字或日期筛选并导出 CSV。

页面使用模拟数据，编辑结果在本次打开期间保留，刷新后恢复初始数据。原型中的 SQL 仅供预览，报告导出为文本，权限操作不影响真实账号。
