计算口径

  • 只统计在籍生。该考的科目是语文、数学、英语，加上首选科目（物理或历史），加上两门再选科目，都从这次考试的选科组合里读。组合里没有的科目不计缺考，所以未选考科目的 0 分不会算成缺考。
  • 该考科目里有一门是 0 分或没有分，就算该门缺考，这个人进入名单。该门 0 分与缺考记法相同。
  • 整场缺考：这场在本校没有成绩行，且全市任何学校都没有这个人的成绩行。这样的人按上一场的选科组合，六门都记缺考。在别的学校有这场成绩行的，不算本校缺考。
  • 上一场取考试时间早于这次、且最近的一场。选了班级时，这次有成绩的按这次班级，整场缺考的按上一场班级。
  • 选科组合看不清的，单独列出，不猜，也不算进缺考人数。
  • 名单里的姓名是否显示，跟随系统的匿名开关。开启时只显示学号。
